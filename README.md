Big Data Analytics project using Python, Pandas, SQL
# Smart City Demand Analysis

##  Objective
Analyze traffic, electricity, and water demand using Big Data concepts.

##  Technologies
- Python
- Pandas
- SQLite
- Seaborn

##  Key Features
- Data cleaning and preprocessing
- GroupBy aggregations (MapReduce simulation)
- Time-based and weather-based analysis
- Demand pattern visualization

## Results
- Identified peak traffic hours
- Analyzed weather impact on demand

##  How to Run
1. Open Jupyter Notebook
2. Run all cells
